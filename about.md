# W Click GUI

Android-targeted starter project for Geometry Dash 2.2081 using Geode.

Includes a W button on the main menu and settings for CBFH's 1–20 frame window plus four utility toggles. The current starter build does not implement automatic frame-perfect jump execution or pause-menu integration yet.

Build with a compatible Geode SDK and Android NDK:
- `geode sdk install-binaries -p android64` (64-bit Android)
- `geode build -p android64`

For a 32-bit Android device, install `android32` binaries and build with `-p android32`.
